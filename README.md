# QuranDelve 🌙

QuranDelve is an Islamic learning website concept designed to help users explore Quranic knowledge through interactive learning, quizzes, and an AI-powered guidance assistant.

## Features
- 📖 Islamic learning and educational content
- 🧠 Interactive quizzes and knowledge challenges
- 🤖 AI guidance assistant concept
- 📱 Responsive, user-friendly interface

## Current Status

QuranDelve is a **front-end project and work in progress**. The AI assistant is currently a visual concept only. It is not connected to an API or backend, so its AI functionality is not operational at this time.

## Technologies
- HTML
- CSS
- JavaScript
- Bootstrap 5.3

## Purpose

This project explores how web development and AI could support accessible, engaging Islamic education. Future development could include integrating an AI API to power the guidance assistant.
